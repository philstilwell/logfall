Fallacy Detective

Investigate the argument. Check the evidence. Test your own reading.

Fallacy Detective examines reasoning in mainstream news, commentary, and widely reported public claims. Try each case before revealing the analysis. We distinguish a documented reasoning error from a hypothetical reader inference—and allow “no demonstrated fallacy” as a finding.

How new features are chosen

Each investigation starts with a consequential, recent claim, then follows the article and its evidence. A strong case identifies the actual speaker, reconstructs the argument fairly, tests the strongest reasonable defense, and explains how to improve the reasoning. A headline match alone is never a verdict.

What gets flagged

We look for public importance, independently visible coverage, and a specific inference that can be checked. Sources span outlets and subjects; the same evidential standard applies regardless of political alignment. Multiple fallacy labels are not a target.

Why self-control still matters

Distinguish the outlet’s own claim from a quotation it reports, and both from an inference you supply. Ask whether agreement or hostility changes the evidence you demand. A mistake in reasoning does not by itself make the conclusion false.
