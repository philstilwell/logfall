# LogFall Asset Inventory

## Tracked Public Assets

- `assets/fallacy-*-poster.webp`: 144 web-optimized fallacy poster illustrations.
- `assets/assessment-dialogues/*.png`: 40 grayscale dialogue panels used by the Assessment page and PDF.
- `assets/logo.jpg` and favicon files: shared branding and browser icons.
- `assets/phil-stilwell-profile.png`: About page portrait.
- `output/pdf/logfall-dialogue-assessment.pdf`: printable 40-item dialogue assessment.
- `logfall-root-edition.xlsx`: spreadsheet edition regenerated by the site build.

## Source Assets and Scripts

- `site/styles.css`: source stylesheet copied to `styles.css`.
- `site/app.js`: source browser JavaScript copied to `app.js`.
- `site/logfall-map.css` and `site/logfall-map.js`: source map assets copied to `/map/`.
- `scripts/build.mjs`: main generator.
- `scripts/extract_root.py`: dataset extraction/regeneration utility.
- `scripts/headline_scout.py`: Fallacy Detective headline scouting utility.
- `scripts/build_dialogue_assessment_pdf.py`: assessment PDF generator.
- `scripts/render_dialogue_assessment_images.py`: assessment dialogue image renderer.

## Local-Only Artifacts

The following are deliberately ignored and should not be committed unless there is a specific reason:

- `fallacy_rationality_tool.zip`: raw imported source artifact.
- `output/imagegen/`: raw image-generation proofs, experiments, and intermediate panels.
- `tmp/`: temporary review pages and reports.
- `scripts/__pycache__/`: Python bytecode cache.

## Size Notes

- Current tracked visual assets are web-optimized.
- Poster images were recompressed to keep the repository practical for GitHub Pages.
- Old larger poster blobs may still exist in Git history; shrinking Git history would require a separate, deliberate history-rewrite task.
