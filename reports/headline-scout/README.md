# Headline scout reports

These files are generated by the weekly GitHub Action at:

- `.github/workflows/headline-scout.yml`

The workflow runs the local script:

- `scripts/headline_scout.py`

Purpose:

- scan a recent RSS-based headline corpus
- flag likely candidates for fallacy-oriented feature pages
- produce a human-review shortlist rather than auto-publishing diagnoses

Important:

- the scout report is not a verdict
- every flagged headline still needs manual reading and editorial judgment
- a good feature page should distinguish between:
  - a fallacy in the headline itself
  - a fallacy a fast reader is likely to infer from the headline
  - a fallacy that only appears deeper in the article or later commentary
