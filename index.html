Logical fallacies made clearer, more teachable, and easier to compare.

LogFall is a practical reference for spotting, naming, comparing, and correcting reasoning mistakes. Each entry combines a definition, a concrete example, case studies, a companion illustration, related fallacies, and a guided practice tool.

How to use the site

1. Start with a category

Browse the taxonomy when you know the kind of reasoning error but not the exact fallacy name.

2. Jump to a detail page

Each fallacy page brings together a concise definition, a concrete example, explanatory notes, a rationality lab, case studies, and nearby entries.

3. Compare similar mistakes

Use the related fallacies, case studies, and practice tool to separate look-alike mistakes that often get confused in real arguments.
