Perfect solution fallacy

Occurs when an argument assumes that a perfect solution must exist and/or that a solution should be rejected because some part of the problem would still exist after it has been implemented.

ConceptualEvidential

Definition

Occurs when an argument assumes that a perfect solution must exist and/or that a solution should be rejected because some part of the problem would still exist after it has been implemented.

Illustrative example

But, Dad! Your $20 is not going to replace the car I crashed! Keep your money!

Case studies

Recent or representative examples that help stress-test the pattern in practice.

Some in the US claim that tighter border controls are "not the solution" to the problem of illegal immigration, and ignore the fact that tighter borders might make a significant difference.
Some argue "You can't stop illicit drug use, so there is no sense in having laws against illicit drugs." Changing the referent from illicit drugs to murder highlights the fallacy.
