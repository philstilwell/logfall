Nirvana fallacy

Occurs when a solution to a problem is said to have no value because it is not perfect.

Conceptual

Definition

Occurs when a solution to a problem is said to have no value because it is not perfect.

Illustrative example

They shouldn't get married since they often have arguments.

Why it misleads

A longer note from the source material, cleaned for readability.

This is very similar to the "perfect solution fallacy." "The perfect is the enemy of the good." ~Voltaire.
