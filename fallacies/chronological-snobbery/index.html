Fallacy profile

Chronological snobbery

Occurs when a conclusion is deemed incorrect because it was commonly held when something else that was clearly false was also commonly held.

EvidentialPerspectival

Definition

Occurs when a conclusion is deemed incorrect because it was commonly held when something else that was clearly false was also commonly held.

Illustrative example

Why must we accept medieval art as having any value when it emerged from the same period in which people burned witches and believed in fairies?

Why it misleads

A longer note from the source material, cleaned for readability.

This is a type of faulty generalization since the error is over-generalizing from a period of several wrong concepts to concluding that all concepts within that period were wrong. A more detailed treatment of faulty generalizations can be found on the supplementary <a href="http://logfall.wordpress.com/inductive-errors/">Inductive Errors</a> page.
