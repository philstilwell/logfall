False analogy

A case in which the analogy fails to coherently maintain a parallel to the original concept on the point in question.

Conceptual

Definition

A case in which the analogy fails to coherently maintain a parallel to the original concept on the point in question.

Illustrative example

Because physicists say mass equals energy, therefore mass can travel the speed of light.

Why it misleads

A longer note from the source material, cleaned for readability.

If some system <i>A</i> has both function <i>X</i> and function <i>Y</i>, and some system <i>B</i> has a function <i>X′</i> corresponding to <i>A</i>'s function <i>X</i>, then the system <i>B</i> should also have a function <i>Y′</i> that is analogous to <i>A</i>'s function <i>Y</i> for the analogy to succeed.

Case studies

Examples and discussion prompts attached to the original source entry.

Consider the following argument. <blockquote>Teaching teenagers how to succeed in marriage prior to being married is like trying to teach someone how to ride a bicycle prior to placing them on a bicycle. </blockquote>This is a false analogy in that it assumes the same type of learning mechanism used for the muscular memory of cycling is also used for grasping the dynamics of marriage.
Consider the following argument. <blockquote>Dating is like gambling. You'll win a few, and lose a few.</blockquote>This is a false analogy in that it ignores the non-randon aspects of selecting a date.
