Check Yourself

A mixed 10-question assessment that does not reveal the answer in the title.

Each set draws from the full LogFall library and mixes fallacies so visitors have to identify the reasoning mistake from the claim itself. Load another set anytime for a new semi-random group of examples.

Mixed assessment runner

The assessment uses clear example claims, multiple-choice identification, and immediate answer review with links back to the relevant fallacy pages.

How it works

Each run gives you 10 example claims. Choose the best fallacy label for each one, then grade the whole set at once to see your score and review the correct answers.

What is in the mix

Sets are drawn from all 143 fallacies in LogFall, with especially common categories such as Evidential, Conceptual, Tactical, Emotional appearing often enough to keep the assessment realistic.
